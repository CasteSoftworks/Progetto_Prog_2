# Progetto Programmazione 2 - Inverno 2025

Il progetto prevede una specie di simulzaione di borsa con aziende che si quotano in diverse borse a diversi prezzi e broker che comprano e vendono azioni e depositano o prelevano denaro da un fondo
Le azioni seguono una politica di prezzo che fa:
* dimuinure se vengono vendute
* alzare se vengono comprate
* entrambe le precedenti
* duplicare o dimezzare se vngono vendute/comprate almeno X azioni
* duplicare o dimezzare se vengono vendute o comprate azioni di aziende (o in borse) che hanno la prima lettera uguale a una lettera L o una vocale
